Get Started

快速开始

三步即可开始分析。软件为单文件绿色 EXE，无需安装 Python 或配置环境变量。

1
下载并运行
从下方"下载"区获取 FluMutationAnalyzer_v5.0.0.exe，双击运行。首次启动会自动释放 Nextclade 数据集到本地 AppData。 
FluMutationAnalyzer_v5.0.0.exe
# 大小 ~91 MB · 无需安装
2
导入 FASTA 序列
点击"打开文件"或直接拖拽 FASTA 文件到主窗口。支持单样本模式与批量模式（拖入多个文件即自动切换到批量）。 
Sample_001.fasta
Sample_002.fasta
... (拖拽即可)
3
分析与导出
软件自动完成亚型鉴定 → 突变检测 → 耐药 → 重配 → 谱系定位全流程。分析完成后在"导出"面板生成 Word/Excel/Markdown 报告。 
报告包含：
· 封面 + 执行摘要
· 关键位点表格
· 参考文献附录

系统要求与外部工具

操作系统
Windows 10 / 11（64 位）· macOS 与 Linux 需从源码运行
内存
≥ 4 GB（批量 30+ 样本建议 8 GB）
磁盘
≥ 500 MB 可用空间（EXE 91 MB + Nextclade 数据集 + 参考库）
Python（可选）
≥ 3.10 · 依赖 PySide6 ≥ 6.5、Biopython ≥ 1.81、matplotlib ≥ 3.7、python-docx ≥ 1.1、openpyxl ≥ 3.1
IQ-TREE 2（可选）
≥ v2.2.0 · 用于最大似然进化树与 ASR；缺失时回退到纯 Python NJ 法
Nextclade CLI（可选）
v3.x · 用于精准谱系定位；EXE 已内置数据集，缺失时使用纯 Python 引擎
HyPhy（可选）
≥ v2.5 · 用于 FUBAR 真 dN/dS 选择压力分析；缺失时使用简化版
MAFFT（可选）
v7.x · 多序列比对预处理；IQ-TREE 内置比对逻辑，极少需要
