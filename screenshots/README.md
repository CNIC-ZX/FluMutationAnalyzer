# 截图目录说明

请将软件截图放入本目录，按以下命名（`index.html` 已按此路径引用）：

| 文件名 | 内容建议 |
|---|---|
| `01-overview.png` | 分析总览仪表盘（8 卡片导航页） |
| `02-mutation.png` | 突变位点总表 + 位点图谱（基因组浏览器风格） |
| `03-phylo.png` | 谱系定位进化树（IQ-TREE 或 Nextclade 输出） |
| `04-report.png` | 专业报告导出预览（Word/Excel 封面页） |

## 格式建议

- **尺寸**：宽 ≥ 1600px，长宽比接近 16:10（页面按 16:10 裁剪显示）
- **格式**：PNG（无损）或 JPG（质量 ≥ 85）
- **单张大小**：建议 ≤ 500 KB，避免拖慢首次加载
- **脱敏**：如截图含真实样本名或内部路径，请先打码或替换为示例数据

## 上传后如何生效

1. 你把截图发给我（或自己放到本目录并告诉我文件名）
2. 我把 `index.html` 中 4 处 `.screen-placeholder` 替换成 `<img src="screenshots/xxx.png" alt="...">`
3. 再执行一次发布即可

## 后续维护

- 版本更新时，如界面变化较大，请重新截图覆盖对应文件
- 如需增加新截图，在 `index.html` 的 `.screens-grid` 中追加一个 `.screen-card` 块即可
